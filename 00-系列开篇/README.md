# 系列开篇：让 AI 帮你做 App

[返回课程总索引](../README.md) · [观看系列开篇](https://www.bilibili.com/video/BV1wvsA6VEhN/)

有一个想法，但不知道怎么把它做出来，可以从一个具体、可验证的小问题开始。

这套课不要求先学完编程语法。我们会一起练习：向 AI 说明需求，找到项目文件，运行程序，检查结果，遇到问题把操作和现象讲清楚。

你可以是学生、上班族，也可以是有行业经验、想尝试做一个应用的人。后续会分享真实企业 AI+ 案例，已开放内容以课程总索引为准。

## 怎么跟课

- 视频看操作，图文手册查步骤，提示词一次复制一段。
- 先使用配套虚构练习文件，把自己的原件留好。
- AI 说“完成”后，自己运行并核对结果。
- 每做完一个案例，留下需求、使用说明、开发日志和测试报告。
