# 此地无银 课程源码使用说明

让 AI 帮你做 App01，资料包2.0。Windows文件加密学习原型；先用随包的小体积虚构样例，不用于重要资料的唯一保护。

## 先运行还是从头开发

想直接试成品：把本课完整的源代码目录解压到固定位置，在豆包桌面端的工作页签选择它，发送提示词文档的S1。让豆包先核对本机Python，创建项目环境并安装依赖，确认后启动main.py。

想学习从需求到实现：另建一个空项目，按图文开发手册和提示词①至⑦操作。不要把新生成的项目直接覆盖到这份参考代码上。

## 文件应该齐全

- main.py：程序入口。
- ui.py：窗口和按钮。
- crypto_core.py：加密与还原逻辑。
- hello.py：第一次运行验证。
- requirements.txt：固定运行依赖cryptography==50.0.2。
- assets/app.ico：程序读取的Windows图标；不要单独改名或删掉。
- assets/app_256.png：PNG预览；assets/icon_source.png：图标原图。
- REQUIREMENTS.md、DEVELOPMENT_LOG.md、TEST_REPORT.md：需求、整理后的开发记录、此次核验报告。

## 在 Windows 准备环境

本包不携带另一台电脑的.venv、缓存、快捷方式或EXE。项目环境要在你的电脑上新建。

原录制项目使用Python 3.13系列。已经有可用且兼容的环境就先验证，不因为视频版本不同而重装。请先让豆包核对实际解释器路径、tkinter与运行方式，不要复制录制机器的用户路径。

如果已经确认安装了Python 3.13，且py -3.13指向它，可在文件资源管理器打开本目录，在地址栏输入powershell，逐条执行：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

若没有这个解释器，先按官方来源准备，不连续猜命令。也可以让豆包把第一条换成你已核实的Python完整路径，正确处理路径中的空格。已有.venv时先检查，不能为跟课而删除其他项目环境。

不用激活脚本也能按上面的完整路径运行。pip失败时先看错误，安装成功后再启动。

## 加密与解密

1. 加密页手动选择一个文件或一个文件夹，输入并确认文件密码。提示是可见的，不填写密码。
2. 选择加密包保存位置，使用新的.pyenc文件名，再开始加密。检查原件仍在，新包确实生成。
3. 解密页选择.pyenc，点读取提示/信息，选择用文件密码解密，输入对应密码。
4. 输出选择空目录或新建目录。还原后亲手打开文件，比较内容；文件夹还要检查子目录。
5. 密码错误、输出重名、输出目录非空时，按提示处理，不把错误窗口当成成功。

源码对提示与密码完全相同的情况作拦截，但不会识别所有可能泄露密码的提示写法；提示请留空或使用不含密码的普通文字。不要在公开反馈中提供密码。

## 恢复功能

加密时勾选启用恢复，另外设置并确认一个与文件密码不同的恢复密码。之后才能在解密页选择用恢复密码恢复。未启用恢复的旧包不能事后补开。恢复还原的是文件内容，不显示原文件密码。

同一个恢复密码可以用于多个在加密时为它启用恢复的包；它不是所有包通用的密码。

## 图标与快捷方式

assets/app.ico供Windows使用，另外两张PNG供预览和设计参考。做快捷方式时按你自己的项目位置设置解释器、main.py和工作目录，再使用app.ico。先关闭已有窗口，再双击快捷方式验证。

项目被移动后快捷方式可能失效；不能只拷一个.lnk给别人使用。本包不含独立安装器，Mac不是这份GUI的直接运行目标。

## 故障处理

- 没有cryptography：确认依赖安装到当前项目的.venv，不是另一个Python。
- 无法创建窗口：保留完整终端错误，检查tkinter与解释器。不要只双击后猜原因。
- 密码框退格卡死：记录输入法、Python/Tk版本和真实操作，先让豆包给最小处理方案。原录制机器换环境后复测的做法不是所有电脑的统一答案。
- 提示目录非空：换新空目录，不删除未知用途的文件。
- 双击.pyenc不识别：在本工具中选包解密，不用记事本打开。

## 验证边界

原资料包整理时在macOS、Python 3.12.14、cryptography 50.0.2中直接测试核心逻辑18项，全部通过，详见TEST_REPORT.md。没有在新Windows电脑上重新验证GUI、输入法与快捷方式。

文件归档和解密在内存中进行，界面同步执行，只适合课程小样例。并发覆盖、磁盘中断、大文件和恶意构造包等未做完整验证。使用成熟加密库不等于本原型已完成安全审计。
