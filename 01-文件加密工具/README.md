## 准备步骤

1. 准备 Windows 电脑，安装并登录[豆包桌面端](https://www.doubao.com/download/desktop/)，确认能使用“工作”页签与本机项目。
2. 建立自己的空项目目录；跟做和试现成源码用不同目录。
3. 让豆包先检查本机 Python 的真实版本与路径，需要时再安装。
4. 跟做权限建议“始终询问”。录屏中的“全部允许”是演示选择。
5. 把练习样例放到能找到的位置，输出放到新建目录，保留原件。

## 版本与验证

这是第一课现有资料包 v2.0 的仓库整理版。旧 Word 的部分页面保留原系列名，在线版已统一新名称。源码与图标未改业务内容，见[来源与文件指纹](资料来源.json)。

原包记录了 macOS 下 18 项核心逻辑检查；[测试报告](源代码/TEST_REPORT.md)保留其日期和环境。本轮仅整理、核对和发布，不将历史结果写成新的实机验收。Windows 窗口、输入法和快捷方式需要在自己的电脑验证。

先用小体积虚构样例。本项目不是独立 EXE 安装包，也不是经过完整安全审计的商业加密产品。
