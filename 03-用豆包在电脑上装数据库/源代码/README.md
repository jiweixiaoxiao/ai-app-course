# 家具表 SQL

想知道豆包写了什么，可以用文本编辑器打开[家具表练习.sql](家具表练习.sql)。这是作者在 Windows 练习中留存的原文件。课程通过豆包操作 MySQL，没有单独的应用程序或图标。

这个脚本创建练习库 practice 和家具表 furniture，写入六条样例，最后按编号查询。重复执行时，它会把同编号记录更新为样例值。例如，删掉的餐桌会回来，衣柜数量会恢复为 1。只在专用的空练习库中使用，先检查是否已有同名库表和其他人的数据。

跟视频逐步观察「一条 → 六条 → 五条」时，从提示词 02 开始即可。想直接看六行样例时，可将 SQL 作为附件交给豆包，先让它核对目标是自己的空练习库，再执行并查询。文件采用 MySQL 的语法和排序规则，其他数据库或旧版本可能需要调整。

文件字节与录制工程原件一致。已对照实录核查六个编号和数值，本次资料整理未在新 Windows 环境重装或重新执行 SQL。
