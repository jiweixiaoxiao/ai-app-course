MySQL Windows 安装经验教训 · 观众跟做版

这份文字根据录制电脑的安装经验整理。把它作为附件发给豆包，同时告诉它你卡住的步骤和实际报错，请它针对你的电脑进行检查。

一、已经装过
先请豆包列出本机已有的 MySQL 实例、服务状态、连接地址与端口。能连接就复用原实例。只检测到 mysql 命令时，还要实际连接并查询服务端版本。

二、弹窗或权限不足
看清软件名称、来源和需要授权的操作，再由你在 Windows 确认。录制电脑使用当前用户登录后启动的方式。自己的电脑如果受单位管理，请按单位允许的方式安装。让豆包解释当前选择以及以后如何启动。

三、下载、端口或连接失败
让豆包从 MySQL 官方来源获取安装文件并检查签名。下载失败时，先确认下载是否完整。端口占用时，先查是哪个程序或已有数据库在用。连不上时，依次检查服务是否运行、地址和实际端口是否匹配、当前账号是否有权限。密码只在本机输入。

四、重启后从哪里继续
只有 Windows 提示重启时才重启。回到刚才的豆包项目，让它先检查已完成的步骤。看到版本和可用连接后再建家具表。录制示例为 127.0.0.1:3306，具体版本和端口以本机返回为准。

五、确认存下了什么
让豆包从本机练习库查询家具表。第一次应该有编号 1 的餐桌。若结果不同，先查库名和表名再继续写入。保留已有资料。

提问示例
我在【这一步】看到【完整报错，删去密码】。请结合本文检查本机状态，告诉我接下来只做哪一步，以及看到什么说明这一步成功。
