# 用豆包在电脑上装数据库，存下你的第一条数据

给搬家清单记下一张棕色餐桌。让豆包在 Windows 上装好 MySQL，把餐桌存进去，再从本机查回来。第一次接触数据库、从这节课开始，也能跟做。

**离线跟做**　[下载第三课完整学习资料 v1.0](下载/第三课完整学习资料-v1.0.zip)，先解压，打开「00-先读我.md」。包内有图文手册和分步提示词两份 Word，也有可以直接复制的 TXT。

**在线跟做**　打开[完整图文手册](教程/完整图文手册.md)和[分步提示词](提示词/README.md)。在豆包电脑版选「工作」，新建练习项目。每次只发当前这一步，看到实际结果再继续。

| 做到哪一步 | 怎样确认 |
| --- | --- |
| 安装并启动 MySQL | 让豆包实际连接本机，报出服务端版本、地址和端口 |
| 存下第一条 | 从家具表查回编号 1 的餐桌，数量 1，正方形、9 成新、棕色 |
| 练习增删改查 | 先从一行增到六行，删掉编号 1 后剩五行，编号 6 的衣柜改为 4 个 |
