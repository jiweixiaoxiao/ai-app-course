# 在 Mac 上选择安装材料

**先看芯片和系统。** 苹果菜单 → 关于本机，记下 Mac 芯片和 macOS 版本。Apple 芯片选 arm64，Intel Mac 选 x64。先在 Apple 的 Xcode 兼容表确认 Xcode 能运行在你的 macOS 上，并支持手机系统；录制版本供对照。

| 项目 | 获取与核验 |
|---|---|
| Xcode | 从 [Mac App Store](https://apps.apple.com/cn/app/xcode/id497799835) 获取，先看 [Xcode 系统要求](https://developer.apple.com/xcode/system-requirements)。首次运行后通过 Xcode → Settings → Components 管理 iOS 平台。|
| Flutter SDK | [Flutter 官方归档](https://docs.flutter.dev/install/archive) 或本课网盘版 05-安装包。实录用 macOS arm64 3.50.1 stable、Dart 3.14.0。把解出的 flutter 目录放在自己可写的位置，按提示词 03 将其 bin 加入 PATH，重开终端核验。|
| Git | 完成 Xcode 首次设置后运行 `git --version`。本集录制环境使用 Apple Git。|
| iPhone 配对 | [Apple 的设备管理说明](https://developer.apple.com/documentation/xcode/managing-your-simulated-and-physical-devices-in-device-hub) · [Flutter 的 iOS 环境设置](https://docs.flutter.dev/platform-integration/ios/setup)。|
| 个人签名 | [Apple 账户、免费测试和七天有效期](https://developer.apple.com/help/account/basics/about-your-developer-account/)。|
| 主屏独立运行 | [Flutter 构建模式](https://docs.flutter.dev/testing/build-modes)。真机按第 10 条装 Release。|

本次录制 App Store 的 Xcode 本体标为 10.35 GB，所选 iOS 27.2 组件行标为 16.64 GB。不同版本和已安装内容会改变大小。已装完整 Xcode 和平台支持时直接回豆包复核。
