# 卡住时从哪一项继续

| 现象 | 下一步 | 看到什么再往下走 |
|---|---|---|
| 装好 Xcode，没出现带版本号的组件窗口 | Xcode → Settings → Components，看 Platform Support 中的 iOS 行。缺项时点本行 Get。| 第 02 条列出的四项检查通过。 |
| 终端找不到 flutter | 比对 SDK 的真实目录和 PATH 中的 bin，再开新终端。 | flutter --version 可读。 |
| Xcode 打开后看不到 Runner 工程 | 让豆包从工程里的 ios/Runner.xcworkspace 打开项目。 | 左侧看到蓝色 Runner。 |
| 设置中找不到开发者模式 | 解锁手机，用数据线连接并信任电脑，从 Xcode 发起配对后再找设置。 | 重启后确认启用，设备列表出现自己的手机。 |
| 选了 Personal Team 却报 Failed Registering Bundle Identifier | 保持团队选项，给该练习项目更换自己的唯一编号，点击空白处等待自动签名。 | 原位置的注册错误消失，再看下游描述文件提示。 |
| 不受信任的开发者 | 设置 → 通用 → VPN 与设备管理 → 自己的开发者 App，按提示确认。 | 手机上能打开当前签名的 App。 |
| 拔线后点开只有英文黑屏 | 根据原文确认调试版限制。接回同一部手机，发 10，以 Release 重装。 | 拔线、划掉、从主屏再次打开并能计数。 |
| 上周能用，今天不能打开 | 检查免费测试描述文件是否到期；保留原工程、Team 和 App 编号，用 TXT 末尾重装段。 | 原手机重新签名安装完成，从主屏启动。 |
