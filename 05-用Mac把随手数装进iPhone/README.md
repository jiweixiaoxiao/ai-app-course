# 第五课 · 用 Mac 把「随手数」装进 iPhone

AI创造加｜让 AI 帮你做 App｜资料 v1.0

一台 Mac、一部 iPhone 和一根能传文件的数据线。让豆包帮你准备开发工具，再把 Flutter 计数器装到自己的手机。先点两次加号，再拔掉数据线，从主屏重新打开。签名时用平时下载 App 的苹果账号，在 Xcode 里选自己名字后的 Personal Team。

**从哪里开始**

1. 从零跟视频做：从 [图文开发手册](教程/完整图文手册.md) 第 01 步开始，一次发一段[豆包提示词](提示词/README.md)。04B 让豆包生成计数器。
2. 先运行示例：从[轻量资料 ZIP](下载/第五课完整学习资料-v1.0.zip)解压并复制 counter_demo 到自己的练习目录，按 04C 走。网页上也可以[查看源代码](源代码/counter_demo/)。已保存上节源码的同学可另存一份按 04A 继续。
3. 依次完成配对、签名与真机计数。按第 10 条装 Release，拔线、划掉 App 后重开。免费个人测试签名到期时，用 TXT 末尾的重装提示词。
