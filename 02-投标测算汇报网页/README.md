# 第二课 用豆包做投标测算汇报网页

物业客户想知道一个小区值不值得接。跟着小宋，把客户给的四份虚构 Excel 变成一个能在会上演示的网页。先看云栖项目预计亏多少，再点成本图查钱花在哪儿，还可以当场换一个条件重新测算。

## 先看小宋做出来的网页

下载并解压上面的 ZIP，在「03-源代码与图标 → 汇报网页」双击 index.html。点右上角「自动演示录入」，约 20 秒后会到达第七步。如果已下载整个仓库，[源码说明](源代码/README.md)列出了对应入口。

## 跟着做一份自己的

| 步骤 | 你要完成什么 | 资料 |
| --- | --- | --- |
| 1 定需求 | 先问客户最后一屏想看什么，再让豆包找出对应输入和数据来源 | [会议摘要与样表](练习文件/交给豆包) |
| 2 做网页 | 请豆包先写开发提示词，确认后再生成六步录入、第七步出结果的网页 | [提示词](提示词/README.md) |
| 3 验结果 | 把物业费收缴率从 95% 改成 90%，走一次手动、一次自动，再和 04 号表核对 | [练习说明](练习文件/练习说明.md) · [填写检查清单](检查清单.md) |
| 4 留手册 | 记录怎么打开演示、到哪一步查数，以及遇到的问题和复测结果 | [开发手册](源代码/开发手册.md) · [测试记录](源代码/测试记录.md) |

默认样例预计年亏损 **7.13 万元**，人员费用占总成本约 **74.42%**。只把物业费收缴率改到 90%，预计年亏损为 **15.28 万元**。工作簿中 01 和 04 同属云栖，04 是本次验算依据。
