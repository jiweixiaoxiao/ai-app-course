# 云栖年度测算网页开发手册

## 打开和演示

双击 [汇报网页/index.html](汇报网页/index.html)，保持同目录的 `echarts.min.js` 和它一起移动。网页自带云栖样例，首次打开无需导入 Excel 或安装服务。页头的课程标识由文字与 CSS 绘制，无独立图标文件。

手动演示时，从第一步连续点六次「下一步」。在顶部点任一步可回查；改物业费收缴率到第三步，改岗位人数到第四步。自动演示时，点「自动演示录入」，它会按当前输入从第一步播放到第七步。途中点击顶部步骤可立即停止。点「恢复云栖样例」回到默认数据。关闭页面前把想保留的数记入检查清单。

## 这一版怎样从需求变成网页

以练习区内的会议摘要、会后补充任务和 04 云栖教学模型为依据。第二、三步算面积、报价和预计能收到的收入，第四到六步汇总人员、维保和运营支出，第七步回答盈亏及保本保利。每个输入在各步间共享，改数时用同一套公式重算。01 与 04 是同一个项目，02 与 03 用于辨认另一种项目的字段。

| 要改的内容 | 在 index.html 里查找 | 如何确认 |
| --- | --- | --- |
| 默认项目、面积、人员及费率 | `DEFAULT_STATE` | 点「恢复云栖样例」核对默认输入 |
| 页面顺序和表单 | `STEP_META`、`tplRevenue`、`tplStaff` | 填一个值，前进再返回，仍是刚填的值 |
| 收入和费用计算 | `calculateModel` | 比较 04 表「测算模型」B12 至 B15 与网页的四个结果 |
| 结果图表 | `tplResult`、`costDonutOption`、`initResultCharts` | 断网重新打开，两块仪表、柱图、环图和折线都能显示 |
| 自动演示 | `startAutoplay`、`navigateManually` | 自动播完、点击步骤中断、再启动，当前数据保留 |

样例的 HTML、CSS、JavaScript 和教学数据都在入口文件内。图表使用同目录下的 ECharts 5.5.1。打包时把录课文件从“云栖年度测算演示.html”命名为“index.html”，网页和图表库的文件内容与录课副本一致。开源图表库的许可证与声明在 [第三方许可](第三方许可)。

## 交接前的两个问题

客户如果问“亏损多少”，把第七步的四个数字和 04 表对齐。客户如果问“人为什么这么贵”，先指给他看成本环形图的人员费用，再回到第四步逐项看人数与费用。把复核的环境、结果和问题记在 [测试记录](测试记录.md)。
