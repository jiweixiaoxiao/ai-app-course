# 跟做时的三个常见问题

**在仓库里点开 index.html，为什么只看到代码？**　把[完整 ZIP](下载/第二课完整学习资料-v1.0.zip)下载到电脑并解压。进入「03-源代码与图标 → 汇报网页」，用浏览器双击打开网页，保留同目录的 echarts.min.js。

**页面有数字，图表空白，先查哪里？**　检查 HTML 旁的图表库文件名是否为 echarts.min.js。把整个网页目录复制到新位置，再断网打开。在结果页应看到两个仪表、收入柱图、成本环图和收缴率曲线。

**我把收缴率改成 90%，为什么结果不同？**　第三步改「物业费综合收缴率」，车位收缴率保留教学样例中的 90%。用 04 号表副本的「项目参数」B10 重算，再核对「测算模型」B12 至 B15。把实际值、预期值和操作填入[检查清单](检查清单.md)，再发送[第 05 条提示词](提示词/README.md)。
