# 让 AI 帮你做 App

**从一个具体问题出发，把想法做成自己能运行、能检查、能继续改的软件。**

我是 Charles，这里是 **AI创造加**。这套课程面向没有或只有少量编程经验的人：学生、上班族，以及有行业经验、想验证一个想法的你。

AI 帮忙写代码，我们学习把需求说清楚、运行程序、描述问题、检查结果，再留下一份能继续用的项目。你不必先学完一门编程语言，也需要亲手操作和判断。

1. 看[系列开篇](https://www.bilibili.com/video/BV1wvsA6VEhN/)，了解这套课怎么学。
2. 打开[第一课学习入口](01-文件加密工具/README.md)，选择“从需求跟做”或“先运行示例”。

不会用 Git 也能学习：直接点击下面的图文和提示词，或从[百度网盘](https://pan.baidu.com/s/1JIuMc7b42cAQH_puggxLiQ?pwd=5678)下载第一课完整资料，提取码 **5678**。下载后先解压，不在压缩包预览里运行程序。

## 我们会逐步学到什么

这是一条随课程持续完善的 Vibe Coding 学习路线：

**说清需求 → 准备环境 → 做出原型 → 测试排错 → 交付维护 → 真实场景应用。**

第二课已提供工作汇报网页的跟做资料。后续方向包括数据保存、移动应用、提词器、服务器部署，以及真实企业 AI+ 案例。它们目前属于规划，尚未发布的内容不计入已完成课程。详细方向见[学习路线](学习路线.md)。

## 每个案例都提供什么

- **图文教程**：准备步骤、真实配图、操作与结果核对。
- **分步提示词**：何时使用、复制正文、如何确认完成。
- **代码与图标**：能找到入口和依赖的完整项目，不附另一台电脑的虚拟环境。
- **练习与清单**：虚构样例、预期结果和自己填写的验收记录。
- **问题与交接**：常见卡点、开发记录、实际测试范围。
