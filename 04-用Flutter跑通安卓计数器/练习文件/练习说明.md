# 运行你的第一个安卓计数器

在一个新建的练习目录中从第 01 条开始。用练习名「随手数」或你自己选的名字。保存初始状态和结果，便于失败后重试。

1. 看到 Git 和 Flutter 的版本号，再确认 Android toolchain 已通过。
2. 真机在 Flutter 设备列表里出现后，运行默认项目。打开时是 0，点两次加号后是 2。
3. 改名并重新安装。桌面显示新名字，点开后仍能从 0 开始计数。
4. 可选。为同一个 App 换图标，回桌面核对，打开后复测计数。
5. 若设备没出现，先检查承载数据的线、USB 调试和电脑调试授权。记录执行的命令与真实输出。参考[常见问题](常见问题.md)并填写[检查清单](检查清单.md)。
