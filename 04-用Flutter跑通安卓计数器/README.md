# 第四课 用 Flutter 跑通安卓计数器

AI创造加 · 让 AI 帮你做 App · 课程仓库版 1.0.0

让豆包在 Windows 上帮你准备 Flutter 安卓开发环境。把默认计数器装到自己手机，点两次加号看到 2，再改成喜欢的 App 名字。有需要时可以换图标。

**视频入口待补充。** 手边准备 Windows 10 或 11 x64 电脑、安卓手机、支持传文件的 USB 线，并打开豆包电脑版「工作」。

## 两种跟做方式

1. 在线逐项做。先看 [完整图文手册](教程/完整图文手册.md)，按 01 到 09 在同一会话发送 [分步提示词](提示词/README.md)。已经可用的工具直接验证。出现报错时先核对当前一步。
2. 已有工具链。确认 Android toolchain 通过，设备列表里有自己的手机，参照 [Flutter 模板生成步骤](源代码/README.md)从第 07 条开始。打开计数器、改名，再按需要换图标。
