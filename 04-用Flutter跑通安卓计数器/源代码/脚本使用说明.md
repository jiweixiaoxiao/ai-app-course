# 片尾脚本使用说明

手动路线按当前电脑和官方稳定版选择工具，录制用了 Flutter 3.50.1 和 Gradle 9.5.0。附带脚本 v1.5 固定 Flutter 3.29.0，按自己的 Android SDK 和 Java 配套方案选择组件，默认跳过 Android Studio 和模拟器。两条路线的 ZIP 和 Gradle 版本要分别核对。

1. 把 [脚本](Flutter全环境一键安装脚本.ps1)放进豆包工作文件夹。遇到具体报错，先用提示词 10A 读脚本排错。
2. 换一台电脑时，可以使用 10B。请豆包核对电脑架构、Flutter 和 Java、当前 SDK 位置以及环境变量。脚本可能写入用户 Path 和 Flutter 配置，并调整 Gradle 下载设置。模拟器选项需要另行考虑 Windows 功能和管理员权限。
3. 请本人先阅读 Android SDK 许可并确认安装。脚本提供 `-DryRun` 临时目录演练和 `-VerifyBuild` 构建检查。演练仍需要联网下载工具，首次构建还要下载依赖。 [Android SDK 许可](https://developer.android.com/studio/terms)
4. 检查脚本日志和进程退出码。看到成功后重新打开终端，运行 `flutter --version` 和 `flutter doctor -v`，再运行 `flutter devices` 验证你的手机。

本次资料整理对原脚本做了 PowerShell 语法解析和文件指纹核对。终端中的实际安装与构建结果以你的 Windows 电脑为准。
