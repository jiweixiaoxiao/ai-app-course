# 安卓真机跟做常见问题

## 显示装好了但终端找不到命令

完全退出旧的 PowerShell 或 Windows Terminal，再开一个新窗口。用 `git --version` 或 `flutter --version` 验证。如果仍失败，把原报错发给豆包核对实际安装目录与用户 Path。

## 设备列表里只有 Windows 和浏览器

用支持数据传输的线，解锁手机，确认开发者选项、USB 调试开关和首次连接这台电脑时的授权。如果只是充电，尝试切换到传输文件，并检查手机厂商的 Windows USB 驱动。 [Android 开发者选项](https://developer.android.com/studio/debug/dev-options)

## doctor 通过但第一次构建仍报错

Android toolchain 检查通过后，项目首次构建仍需下载 Gradle 和插件。查看项目的 `android/gradle/wrapper/gradle-wrapper.properties`。按文件记录的版本、包型和官方摘要检查下载，如果报 Java 兼容问题，核对实际 JDK 版本。 [Flutter 安卓环境](https://docs.flutter.dev/platform-integration/android/setup) · [Gradle 发行校验值](https://gradle.org/release-checksums/)

## 手机屏幕显示 DEBUG

默认真机作业运行的是调试构建。完成标准是手机可以打开并计数，改名后保持同一应用的计数功能。
